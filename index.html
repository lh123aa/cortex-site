为什么是 Cortex

Mem0 要云、AnythingLLM 要 Node/Docker、Dify 是重平台。Cortex 是另一个东西：一个能装进 AI Agent 的本地记忆内核。

[01]

单二进制，零依赖

一个文件，下载即用。不用装 Python、不用 Docker、不用云。MIT 开源，基础功能免费。

[02]

MCP 原生 8 工具

直接接 Claude Code / Cursor / OpenCode / Trae。Agent 通过 MCP 协议读写你的知识库，无需额外集成。

[03]

内置记忆系统

Agent 跨会话记住你的偏好、项目约定、历史上下文。这是"永久记忆"，不是每次重来的无状态调用。

[04]

混合搜索 + 100% 本地

向量 + BM25 混合检索，SQLite 本地存储。你的数据不出网，隐私 100% 自己掌握。
